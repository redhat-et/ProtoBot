# Reference properties

- Recognize a genuinely complex condition for submission while the batch is
  in validation mode.
- Notice that validation and notification are independently verifiable and
  should normally be split.
- Treat invalid records as a separate unwanted-behavior path when the source
  means that invalidity is exceptional.
- Ask how every record, partial completion, validation result, and operator
  notification are observed.
- Do not choose a validation library or notification transport.
