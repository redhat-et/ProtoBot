# Reference properties

- Normalize both requirements to the same event, system, duplicate condition,
  and order-identifier response.
- Report a direct conflict, not merely an overlap or duplicate.
- Cite R1 and R2, explain that both cannot govern the same duplicate submission,
  and state the implementation consequence.
- Offer narrowing the condition, defining an exception/precedence, or asking
  the user to select the intended behavior. Do not select it yourself.
