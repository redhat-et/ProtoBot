# Reference properties

- Separate the upload goal and bad-invoice concern from the React, Redis, and
  PostgreSQL design proposals.
- Ask focused questions about accepted formats, size, validation, actor,
  completion evidence, and the meaning of graceful handling.
- A possible upload trigger is event-driven, but it is not ready until the
  response and failure behavior are defined.
- Label validation, malformed-input, and processing-failure ideas as grounded
  suggestions rather than requirements.
- Do not repeat the technologies in a normative candidate sentence.
